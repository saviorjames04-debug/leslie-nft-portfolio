LESLIE LOCKLEAR — NFT PORTFOLIO STARTER

FILES
- index.html = your portfolio website

FASTEST WAY TO USE IT
1. Open index.html in a browser to preview it.
2. Replace the six sample artwork tiles with your real art.
3. Change each artwork title and description.
4. Publish the finished page with a website host such as GitHub Pages or Netlify.
5. Use OpenSea separately to mint/list NFTs, then add your OpenSea links to this portfolio.

IMPORTANT
- Do not share wallet private keys or recovery phrases.
- Mint only work you own or have permission to use.
- Blockchain minting can require transaction/gas fees.
